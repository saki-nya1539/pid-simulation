# PID制御シミュレーション可視化ツール

## 概要

PythonとStreamlitを用いて、PID制御の応答を可視化するシミュレーションツールを作成しました。

比例ゲイン \(Kp\)、積分ゲイン \(Ki\)、微分ゲイン \(Kd\) をスライダーで変更し、制御対象の応答がどのように変化するかを確認できます。

また、応答グラフだけでなく、制御入力グラフ、オーバーシュート、収束時間、定常偏差も表示できるようにしました。

## 使用技術

- Python
- NumPy
- Matplotlib
- Streamlit

## 主な機能

- PID制御のシミュレーション
- Pゲイン、Iゲイン、Dゲインの調整
- 目標値の変更
- 応答グラフの表示
- 制御入力グラフの表示
- オーバーシュートの計算
- 収束時間の計算
- 定常偏差の計算

## 工夫した点

- Streamlitを用いることで、ブラウザ上で直感的にパラメータを変更できるようにしました。
- 応答波形だけでなく、制御入力も表示することで、制御器がどのように働いているかを確認できるようにしました。
- オーバーシュート、収束時間、定常偏差を数値で表示し、制御性能を比較しやすくしました。
- ゲインを大きくしすぎると応答が発散することも確認できるようにしました。

## 実行結果

スライダーでPIDゲインを変更すると、応答グラフがリアルタイムに更新されます。

Kpを大きくすると応答速度が上がり、Kiを加えることで定常偏差を小さくできます。一方で、ゲインを大きくしすぎると出力が振動したり発散したりする場合があります。

## 学んだこと

この制作を通して、PID制御の基本的な仕組みと、比例・積分・微分ゲインが応答に与える影響を理解しました。

また、Pythonを用いた数値シミュレーション、Matplotlibによるグラフ描画、StreamlitによるWebアプリ化の流れを学びました。

## 実行方法

必要なライブラリをインストールします。

```bash  
pip install numpy matplotlib streamlit  
```

Streamlitアプリを起動します。

```bash  
streamlit run app.py  
```

ブラウザでアプリが開き、スライダーでPIDゲインを変更できます。
